# רגע של משפט

פודקאסט יומי על פסיקה אזרחית, מסחרית ודיני ראיות. נכתב ומוקלט בידי בינה מלאכותית. אינו ייעוץ משפטי.

## איך זה עובד

1. כל בוקר נוסף פרק חדש בתיקייה `episodes/<תאריך>/`:
   - `script.txt`: התסריט לקריאה.
   - `script-tts.txt`: גרסת ההקראה (מספרים במילים, ניקוד, הפסקות).
   - `meta.json`: כותרת, תיאור, מקורות, והאם לפרסם (`publish`).
2. הדחיפה מפעילה את `.github/workflows/produce.yml`, שמפיק את הקול ב-Gemini TTS בשני קולות (עמרי ומיכל), מחבר ומנרמל ל-MP3, ומצרף אותו ל-release בשם `ep-<תאריך>`.
3. פרקים עם `"publish": true` נכנסים לפיד `docs/feed.xml`, שמוגש ב-GitHub Pages ונקלט בספוטיפיי.

הגדרות התוכנית, הקולות וסגנון ההקראה נמצאים ב-`podcast.json`. מפתח ה-API נשמר כ-secret בשם `GEMINI_API_KEY`.
